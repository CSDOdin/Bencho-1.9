INFORMACIÓN DEL RESTAURANTE

Términos y condiciones

Consulta esta información antes de utilizar la página.

El menú permite preparar una solicitud de pedido que se enviará mediante WhatsApp, no mediante un sistema interno de pedidos.

Cómo funciona el pedido

Selecciona productos, cantidades, extras, forma de entrega, método de pago preferido y tus datos. La web abre WhatsApp con el mensaje preparado; el envío solo se produce cuando lo confirmas allí. Abrir el enlace no confirma la recepción ni garantiza la preparación.

Precios y disponibilidad

Los precios del menú y el total del carrito son estimados en COP. Bencho 1:9 confirma el importe definitivo, el costo del delivery, las opciones de pago y la disponibilidad directamente por WhatsApp.

Pagos y cambios

No se solicitan comprobantes ni se verifica ningún pago en esta web. El método elegido es una preferencia para coordinar con el restaurante, no una operación de pago. Acuerda los datos de pago, cambios, cancelaciones y posibles devoluciones directamente con el restaurante.

Ingredientes y alérgenos

Las imágenes son orientativas. Consulta ingredientes, alérgenos o restricciones alimentarias antes de confirmar un pedido. Las observaciones no garantizan ausencia de trazas o contaminación cruzada.

Uso responsable

No envíes contraseñas, códigos bancarios ni datos sensibles innecesarios en los campos del carrito. El funcionamiento de WhatsApp también depende del navegador, la conectividad y el servicio externo.
